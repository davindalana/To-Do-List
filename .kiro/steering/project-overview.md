# Project Overview

## What This Is

A simple To Do List mini project. The goal is a clean, functional app where users can manage their daily tasks without unnecessary complexity.

## Core Features

- Add new tasks
- Mark tasks as complete
- Delete tasks
- Filter tasks by status (all, active, completed)
- Persist tasks across page refreshes (localStorage)

## Project Goals

- Keep the codebase small and easy to understand
- Prioritize working functionality over polish
- Suitable as a portfolio or learning project

## Out of Scope

- User authentication
- Backend / database
- Multi-user support
- Notifications or reminders
